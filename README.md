# 말랑말랑 젤리 클레이

손 트래킹으로 허공에서 조물조물 만지는 **사실적인 클레이 웹 장난감**.
복잡한 작업 중 잠깐 뇌를 비우고 가볍게 스트레스를 풀고 싶을 때.

웹캠으로 손을 추적하고 **제스처**에 따라 상호작용이 바뀌는 **다중 클레이 책상(Workspace)**.
여러 클레이를 빚고, 잡아 옮기고, 겹쳐서 하나로 합칠 수 있습니다.

## 특징
- 🖐️ 웹캠 손 인식 (MediaPipe `tasks-vision` HandLandmarker, 최대 2손)
- ✌️ **동적 제스처 인식**
  - ☝️ **포인팅**(검지만 펴기) → 검지 끝(**Landmark 8**)으로 좁은 반경의 세밀한 조형(찌르기/파내기)
  - ✊ **그랩**(주먹/꼬집기) → 클레이를 잡아 손 따라 이동(Drag & Drop)
- 🗂️ **다중 클레이 책상** — 여러 클레이를 배열로 관리. 색칩을 누르면 그 색의 새 클레이가 빈 공간에 **생성(Spawn)**
- 🧩 **위에 얹어 붙이기(Attach)** — 그랩한 클레이를 다른 클레이에 겹치면 하나로 섞이지 않고 **실제 클레이 놀이처럼 위에 덧붙어** 한 덩어리(그룹)로 묶임. 얹힐 때 부드러운 **눌림 애니메이션**. 이후 그룹 전체가 함께 이동
- ✂️ **한 조각 떼어내기(Detach)** — 붙은 조각을 **빠르게 잡아당기면** 그 조각만 그룹에서 분리됨(천천히 옮기면 스택 전체가 함께 이동)
- 🤲 **두 손으로 늘이기** — 한 클레이를 양손으로 잡고 벌리면 엿가락처럼 **쭉 늘어남**
- 🗑️ **휴지통** — 클레이를 잡아 좌측 하단 휴지통에 놓으면 삭제
- 🟤 **찰흙 물성(소성 변형)** — 복원 스프링 없이 눌리고 끌린 모양이 그대로 고정. 점성 장력 + 높은 마찰로 주변 점들이 묵직하게 함께 끌려감
- 🎨 매트한 입체 클레이 렌더링 (깊고 부드러운 그림자 · 무광 음영 · 미세 표면 거칠기, 번쩍임 없음)
- 🫧 하단 글래스모피즘 팔레트 — 파스텔 색상 칩 4개 (호버 시 부드럽게 확대)
- 📹 우측 상단 **플로팅 웹캠 미니 창** — 거울처럼 좌우 반전(`scaleX(-1)`)된 라이브 영상 위에 손가락 끝 + 제스처 색상 마커 표시 (16px 라운드 · 부드러운 그림자)
- 📄 **단일 `index.html`** · 순수 HTML/CSS/JS (빌드 도구 없음, 손 인식 모델만 CDN 로드)

## 사용법
1. `index.html`을 **HTTPS** 또는 **localhost** 에서 엽니다. (카메라는 보안 컨텍스트에서만 동작)
2. "탭해서 시작"을 누르고 카메라 권한을 허용합니다.
3. ☝️ 검지로 찌르고, ✊ 손을 쥐어 옮기고, 색칩으로 새 클레이를 만들어 위에 얹어보세요. 두 손으로 잡아 늘이거나 🗑 휴지통에 버릴 수도 있어요.

### 로컬 실행
```bash
cd "이 폴더"
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```
> `file://` 로 직접 열면 카메라가 동작하지 않습니다(앱이 안내 메시지를 표시함). 로컬 서버나 HTTPS로 여세요.

## GitHub Pages 배포
1. 이 폴더를 그대로 GitHub 저장소에 push.
2. **Settings → Pages → Branch: `main` / root** 저장.
3. 발급된 `https://<user>.github.io/<repo>/` 접속 → HTTPS라 카메라가 바로 동작.

(정적 단일 파일이라 빌드가 없습니다. `.nojekyll` 포함.)

## 조작 팁
- **☝️ 포인팅**: 검지만 펴서 클레이를 찌르면 좁은 반경으로 파이고, 그 모양이 **그대로 고정**됩니다(찰흙처럼).
- **✊ 그랩**: 손을 쥐거나 엄지·검지로 꼬집어 클레이를 잡고 이리저리 옮깁니다.
- **🧩 얹기**: 잡은 클레이를 다른 클레이에 겹쳐 올리면 그 위에 덧붙어 한 덩어리가 됩니다(섞이지 않고 얹힘).
- **✂️ 떼기**: 붙은 조각을 **빠르게 잡아당기면** 그 한 조각만 떨어집니다(천천히 옮기면 통째로 이동).
- **🤲 늘이기**: 같은 클레이를 두 손으로 잡고 벌리면 쭉 늘어납니다.
- **🗑 버리기**: 클레이를 잡아 좌측 하단 휴지통에 놓으면 사라집니다.
- **🎨 생성**: 하단 색칩을 누르면 그 색의 새 클레이가 책상 빈 곳에 생겨납니다.
- 미니 창의 손가락 마커 색으로 현재 인식된 제스처를 확인할 수 있어요(핑크=포인팅, 블루=그랩).
